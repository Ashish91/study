# Web Design Assignment Solutions

This folder contains 18 separate, self-contained HTML solutions corresponding to the assignments in `WebD Assignment questions.docx`. Each page includes the HTML document structure and any CSS it needs. Open any `.html` file in a browser to view it, or edit it in VS Code.

## Files

1. `01-basic-structure.html` — HTML5 structure and comment
2. `02-text-formatting.html` — headings, paragraphs, formatting, and entities
3. `03-block-inline.html` — block and inline behavior
4. `04-semantic-layout.html` — semantic layout and div comparison
5. `05-basic-lists.html` — unordered, ordered, and description lists
6. `06-nested-lists.html` — nested and mixed syllabus lists
7. `07-navigation-menu.html` — horizontal navigation list
8. `08-links-images.html` — internal, external, email, and image links
9. `09-quotation-citation.html` — quotation, citation, abbreviation, and direction
10. `10-multimedia.html` — image, video, audio, and YouTube embed
11. `11-accessibility.html` — language, skip link, alt text, ARIA label, and headings
12. `12-table-sections.html` — caption, table sections, headers, and footer
13. `13-timetable-spans.html` — timetable with `rowspan` and `colspan`
14. `14-nested-responsive-tables.html` — nested table and horizontal scrolling
15. `15-form-inputs.html` — common inputs, labels, and fieldset
16. `16-select-textarea-buttons.html` — select, textarea, and button types
17. `17-validation.html` — form attributes and browser validation
18. `18-admission-project.html` — accessible admission page with table and validated form

## Notes

- Assignments 8, 10, and 11 use remote placeholder images. Internet access is needed to display those images.
- Assignment 10 expects your own `media/sample-video.mp4` and `media/sample-audio.mp3` files alongside the HTML file. Update the source paths to match your filenames.
- Assignment 17 and Assignment 18 submit to `submit.php`. Browser validation works when opened locally, but successful form processing requires a web server and a PHP handler at that path.
- The assignment output screenshots are not embedded into the source document as requirements, so these solutions follow the stated aims and topics.
